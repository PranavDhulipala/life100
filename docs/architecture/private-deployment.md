# Owner-only deployment runbook (not provisioned)
Current GitHub Pages application shell is public. Local browser data is not automatically published, but localStorage is not encrypted and users must not assume a login boundary exists.
1. Create a private backup repository with no collaborators and a fine-grained GitHub token restricted to its contents. Do not share the token in chat or commit it.
2. Deploy the upgraded Worker with the existing Wrangler secret commands. Restrict ALLOWED_ORIGIN to the chosen private frontend origin. Use a unique random ACCESS_TOKEN; the current gateway is single-owner bearer authentication, not OIDC. Configure rate limits before enabling paid AI.
3. Host the built PWA on an authenticated host or behind an identity-aware proxy, with a private origin that cannot be bypassed. Configure an owner-only identity policy; block alternate public origins. The build currently assumes /life100/; match that path or adjust Vite base and test migration. Separate origins do not share localStorage: export an encrypted file and restore in the new origin before retiring the old site.
4. Verify anonymous access fails and authenticated owner access works; check API unauthorized responses, origin restrictions, restore and cross-device transfer. Then disable public Pages if desired. Do not delete old storage until recovery is verified.
5. Backup format v1 uses Web Crypto AES-256-GCM, fresh salt and nonce per encryption, PBKDF2-SHA256 600k iterations; use a high-entropy passphrase and save recovery credentials separately. Backups are encrypted before leaving the browser. The gateway only accepts the encrypted envelope and uses a new GitHub filename. Existing plaintext Git history is not erased by this upgrade; review and remove old data separately if previously uploaded. Local JSON export remains plaintext and explicitly named; do not upload it. This is not a security audit, full E2EE sync, or encrypted local database.
6. AI sends explicitly selected plaintext to providers; do not assume provider processing is private from the provider. No automatic AI indexing.
