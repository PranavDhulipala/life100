# Put Life100 on your iPhone

## GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/ (root)**, then Save.
5. Wait for GitHub to publish the site.
6. On iPhone, open **https://pranavdhulipala.github.io/life100/** in Safari.
7. Tap **Share → Add to Home Screen → Add**.

## Optional cross-device sync

Run `supabase.sql` in a free Supabase project, then enter the project URL, anon key, and email under **Connectors** in Life100.

## Important

Your personal Life100 entries are not committed to this GitHub repository. The app stores them locally unless you explicitly configure Supabase sync or export a backup.
